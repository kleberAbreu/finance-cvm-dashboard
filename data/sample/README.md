# Amostra demonstrativa congelada

Amostra preparada para demonstrar a interface: 48 linhas, seis empresas e oito
trimestres, de 31/03/2024 a 31/12/2025. A unidade monetária dos Parquets é BRL
(reais); os cards convertem para milhões com indicação explícita.

Os valores desta amostra não foram conciliados individualmente com os
demonstrativos originais das companhias. Não trate os valores como cotações
atuais ou dados prontos para decisões de investimento. A amostra serve para
navegação, filtros, demonstrações e testes reproduzíveis do produto.

O modo público força o uso destes três Parquets e não carrega uma base privada,
mesmo que existam arquivos locais de produção. O pipeline fica fora da
navegação e tem um bloqueio adicional para o modo público.
